# Demo Guide

## Before recording
Configure Twitch developer credentials and the exact HTTPS callback. Deploy on a public HTTPS origin. Use a real Twitch channel and an independent viewer account.

## Live walkthrough
1. Open Dr. T → ChatQuest Live and connect Twitch using OAuth.
2. Create The Community Compass with three choices.
3. Add the overlay URL as an OBS Browser Source (1920×1080 recommended).
4. Start the quest.
5. From a real viewer account, send !quest, !join, !vote A, and !suggest Add a dragon.
6. Confirm votes and participation update in studio and overlay.
7. Approve the suggestion and verify it appears on the overlay.
8. Pause/resume, end the quest, and show the result.

A simulated chat test is not a substitute for this live procedure. If credentials or an independent viewer are unavailable, report the live demo as not verified.
