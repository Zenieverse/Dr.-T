## 🌟 Overview & Core Mission

Traditional healthcare software is fragmented, click-heavy, and transactional. **Dr. T** is a multi-disciplinary, full-stack Biomedical Informatics, AI Swarm, Clinical Automation, and Consumer Experience platform. Inspired by a compassionate physician who treated patients with wit, wisdom, and genuine kindness, Dr. T bridges the gap between **rigorous clinical analytics, automated hospital robotics, autonomous agentic economics, and human-centered empathetic guidance**.

Dr. T functions both as a **clinician's productivity force-multiplier** and an **everyday patient/consumer wellness companion**.

### 1. 🩺 Clinical Informatics, ICU Analytics & Socratic Voice
* **Socratic Voice Companion**: Near-zero latency multi-turn voice interaction with customizable personalities (*Empathetic, Clinical, Socratic, Maternal*). Guides patients through somatic stabilization, autonomic burnout reduction, and symptom triage.
* **HL7 FHIR Interoperability Suite**: Complete schema validation and bidirectional mapping for `Patient`, `Observation`, `Condition`, `Encounter`, and `Procedure` conforming to **Epic** and **Cerner** systems, with LOINC / SNOMED-CT indexing.
* **MIMIC-IV Predictive ICU Engine**: Quantitative epidemiology calculators estimating ICU Length of Stay (LOS), 30-day readmission risk, and clinical decompensation based on Harvard Beth Israel Deaconess MIMIC-IV datasets.
* **AI SOAP Note Synthesizer**: Transcribes ambient clinical dialogues into structured subjective, objective, assessment, and plan documentation with exportable `FHIR DocumentReference` JSON files.
* **Medical Imaging AI & RAG Research**: Explains radiographic abnormalities (X-Ray, CT, MRI, Dermal) with grounded semantic retrieval over PubMed, NIH, CDC, and WHO literature.

### 2. ✨ SmArist: Next-Gen AI & AR Consumer Experience Studio
* **Live 3D Virtual Try-On (VTO) Mirror**: 60-FPS real-time webcam tracking powered by 70-point facial mesh neural networks. Realistic physics rendering of **matte, satin, gloss, and metallic** lipsticks, contour blush, eyeshadows, multi-tone hair balayage, luxury eyewear, and kinetic jewelry.
* **14-Dimension Clinical AI Skin Diagnostic**: Medical-grade optical dermal analysis across 14 parameters (wrinkles, hyperpigmentation, hydration, barrier strength, texture, pores, dark circles, redness) with localized SVG zone heatmaps.
* **Longitudinal Dermal Age Progression Simulator**: Interactive slider (-5 to +20 years) demonstrating future collagen degradation and UV protection efficacy.
* **GenAI Haute Fashion & Cloth Drape Physics**: Natural language text-to-outfit synthesis with wind velocity simulation, chromatic harmony matching, and zero-waste sustainability indices.
* **Calibrated Lookbook Retail Cart**: Direct shade-to-cart handoff, real-time promo engine (`PERFECT15`), and cross-device mobile AR transfer via QR code.

### 3. 🤖 Hybrid Clinical Robotics & UiPath RPA Automation
* **Bridging Clinical AI to Legacy EHRs**: Combines **Coded Agents** (TypeScript/Python backend parsing FHIR payloads) with **Low-Code Unattended Robots** (UiPath scripts navigating closed-door browser EHR installations of Epic/Cerner).
* **Automated Patient Intake & Charting**: Automatically enters intake records and updates observation charts without manual clinician data entry.
* **Smart Lab Fulfillment & Action Center**: Human-in-the-loop safety gates requiring clinician sign-off on anomalous lab orders or stat medications.
* **Predictive Alert Dispatching**: Connects ICU telemetry thresholds with automated emergency pager and secure clinical Slack webhooks.

### 4. 🧠 Multi-Agent Swarms, Cognitive Memory & Frontier AI
* **Agent Society Board & Swarm Collaboration**: Parallel role decomposition pipeline dispatching tasks across specialized virtual personas (*Dr. Med, Dr. Edu, Dr. Ops, Dr. Research*) with automated dispute-resolution logs.
* **Persistent Relational Memory Graph**: Immutable semantic memory extractor (Qwen / Gemini) that builds bidirectional knowledge graphs linking patient milestones, prescriptions, and lifestyle habits.
* **Frontier Reasoning Suites**: Integrated evaluation benches for **NVIDIA Nemotron**, **MedGemma (HAI-DEF)**, and **ARC-AGI Fluid Intelligence Generalization**.

### 5. 🔐 Zero-Knowledge Privacy, Sovereign DIDs & x402 Commerce
* **Sovereign Care Fabric & Maternal Privacy Shield**: Generates client-side Decentralized Identifiers (`did:drt`) with Zero-Knowledge (ZK) nullifier proofs to scrub PII, IP addresses, and raw telemetry before transmission.
* **Stellar Soroban ZK Attestation Portal**: Anonymous community voting and support attestations powered by Merkle membership proofs and Pedersen commitments.

## 🚀 Quick Start & Local Setup

### 1. Prerequisites
* **Node.js**: v20.x or higher (LTS recommended)
* **Package Manager**: `npm` (v10.x+) or `pnpm`
* **Modern Web Browser**: Chrome, Edge, Firefox, or Safari with WebCam permissions enabled for AR try-on.

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/Zenieverse/Dr.-T.git
cd Dr.-T

# Install all workspace dependencies
npm install
```

### 3. Environment Variables (Optional for Offline Sandbox)
The system operates seamlessly in offline simulation mode out of the box. To enable live Gemini AI or external cloud endpoints, configure `.env`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```

### 4. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to: **`http://localhost:3000`**

### 5. Production Compilation & Launch
```bash
# Slices static client into dist/ and bundles backend into dist/server.cjs
npm run build

# Start the compiled production server
npm run start
```
