## 🌟 Executive Overview

**Dr. T** is an enterprise-grade, full-stack intelligence ecosystem embodying **"Polymath with Heart"** (♾️) — uniting empathetic patient-facing conversational AI, evidence-grounded biomedical informatics, clinical decision-support, multi-agent medical swarms, autonomous software engineering (LIFEWEAVE Gemma 4), tamper-evident distributed provenance (**Hedera Commons**), cinematic evidence generation, veterinary diagnostics, and **Trib-House: The Living Library & Treehouse Campus Commons**.

Built with TypeScript, React 18, Vite, Express, and Tailwind CSS, the platform delivers holistic health intelligence, intergenerational slow reading, interactive knowledge graph navigation, cryptographic notarization, and web-native operating environments.

## 🚀 Core Integrated Modules

### 1. ♾️ Dr. T — Polymath with Heart (Socratic Clinical Companion)
- **Empathetic Socratic Dialogue**: Non-judgmental, evidence-grounded health inquiry analyzing symptoms, lab values, and sleep logs with warmth and scientific rigor.
- **Multilingual Fluency**: Real-time communication across 10+ languages (English, Vietnamese, German, French, Spanish, Mandarin, Japanese, Arabic, Hindi, Portuguese).
- **Voice Mode (Live STT/TTS)**: Real-time Speech-to-Text and Web Audio API Text-to-Speech with natural pitch, pacing, and emotional warmth.
- **Clinical Safety Triage**: Automated green/yellow/red risk classification with action recommendations and physician consultation guidelines.
- **Structured SOAP Documentation**: Transforms patient encounters into standardized Subjective, Objective, Assessment, and Plan clinical documentation.

### 2. 🛡️ Hedera Commons — Trust, Provenance & Verification Center
- **Zero-PHI On-Chain Guarantee**: Strict privacy barrier keeping all confidential medical records, clinical notes, and PII in secure off-chain storage. Only deterministic 256-bit SHA-256 fingerprints are anchored to public distributed ledgers.
- **Hedera Consensus Service (HCS)**: Immutable topic-based notarization (`Topic ID: 0.0.5892147`) capturing decentralized consensus timestamps, sequence numbers, and running hashes with sub-2s finality.
- **Independent Mirror Node Verification**: Direct REST verification querying official Hedera Mirror Nodes to validate anchored hashes against local artifact copies without requiring private keys.
- **Drag-and-Drop Notarization**: Instant client-side hashing for research papers (PDF), datasets (CSV/JSON), model weights, and images using standard Web Crypto API.
- **Exportable Institutional Certificates**: Single-click generation of printable HTML Provenance Certificates and machine-readable JSON audit proofs.
- **1-Click Batch Ledger Audit**: Concurrent verification engine checking all registered platform artifacts against Mirror Node consensus ledgers with live progress tracking.
- **Multi-Tier Privacy Compliance**: Enforced classifications across `PUBLIC`, `INTERNAL`, `PRIVATE`, and `SENSITIVE` (HIPAA Safe Harbor & GDPR Article 9).

### 3. 🤖 LIFEWEAVE — Gemma 4 Autonomous SWE Developer Agent
- **Evidence-Guided Reasoning Engine**: Engineered for the Google Gemma 4 Developer Agent Competition, operating on real multi-file codebases.
- **Candidate Verification Gate (5 Invariants)**: Eliminates false hypotheses by enforcing Reachability, Activity, Implication, Contradiction Checks, and Upstream Causal Hierarchy.
- **10-Task Synthetic Benchmark**: Proven 100% patch pass rate across synthetic localization traps, graph dependencies, redirect loops, and multi-file repairs.
- **Living Code Map & Secret Redaction**: Dynamic AST relationship graph with automated masking of credentials and clinical logic boundaries.

### 4. 🎬 Dr. T Cinema — Evidence-to-Screen Production Studio
- **Biomedical Evidence Screenplays**: Transforms clinical syntheses and literature into structured, scene-by-scene screenplays with evidence markers (`[C-xxx]`).
- **Parallel Search & Ledger**: Visual citation graph linking visual dialogue lines directly to underlying medical publications.
- **Director Storyboard & Production Export**: Generates lens profiles, lighting palettes, SRT subtitles, and complete production packages.

### 5. 🌳 Trib-House: The Living Library & Treehouse Campus Commons
- **12 Biophilic Treehouse Pavilions**: Interactive 1:500 masterplan architecture connected by canopy skywalks (Reading Houses, Research Commons, Silent Future Archive, Elder Story House).
- **Diurnal Climate & Light Simulator**: Interactive transitions across 8 lighting/weather states (Dawn Mist, Midday Shade, Monsoon Deluge, Golden Sunset, Dark Sky Night, and 100-Year Horizon 2126 CE).
- **18 Living Knowledge Branches**: 1,480+ curated volumes across Earth Sciences, Systems Biology, Indigenous Wisdom, Philosophy, AI & Cybernetics, and Intergenerational Stewardship.
- **Distraction-Free Reading Nest**: Slow reading environment with customizable typography, margins, reading speeds, and ambient forest soundscapes.
- **Hedera Provenance Bridges**: Direct one-click cryptographic notarization linking living library manuscripts to Hedera Consensus Service.

### 6. 🐾 K9Whisperer / Pet Whisperer AI (Veterinary Diagnostics)
- **Multi-Species Health Intelligence**: Tailored diagnostics and wellness tracking for canines, felines, birds, and companion animals.
- **Symptom & Behavioral Decoder**: Correlates vocalizations, activity changes, and dietary patterns with potential health conditions.
- **Toxicity & Nutrition Index**: Real-time safety verification for human foods, household plants, and ambient toxins.

### 7. 💻 OpenWebOS Desktop Environment & WebMCP Hub
- **Web-Native Desktop OS**: Multi-window desktop with drag-and-drop windows, taskbar, dock, file manager, system monitor, and embedded terminal.
- **WebMCP Automation Pipelines**: Multi-step automated task orchestration for healthcare workflows and administrative execution.

### 8. 🌌 GreenieVerse Galactic Farm Simulation

- **Market Arbitrage Terminal & Cosmic Meteor Physics**: Real-time supply-demand pricing predictions and dynamic particle-canvas meteor shower effects.

### 9. 📊 Health Intelligence & Biometric Timeline

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `>= 20.0.0`
- **npm**: `>= 10.0.0`

### Installation & Development

```bash
# 1. Clone the repository
git clone https://github.com/Zenieverse/Dr.-T.git
cd Dr.-T

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env
# Edit .env with your credentials (see configuration section below)

# 4. Start full-stack development server (Port 3000)
npm run dev
```

The application will be accessible at `http://localhost:3000`.

## 🔒 Security & Privacy Commitments

1. **Strict Zero-PHI Barrier**: Sensitive clinical records, patient identifiers, and credentials are mathematically excluded from on-chain transactions. Only irreversible SHA-256 hashes are anchored to Hedera.
2. **Server-Side Secret Isolation**: Private keys (`HEDERA_PRIVATE_KEY`) and API keys (`GEMINI_API_KEY`) reside exclusively in server memory and are never bundled into client scripts.
3. **Audit Provenance Verification**: Independent Mirror Node REST queries allow any auditor to verify timestamps and content integrity without trusting intermediate servers.
4. **Clinical Safety Guardrails**: Socratic medical dialogues clearly separate general educational health insights from urgent clinical escalations.
